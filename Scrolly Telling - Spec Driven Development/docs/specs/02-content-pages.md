# Spec 02: Content Pages

## Goal

Provide regular reading pages that inherit the story's visual language while expanding the project in a calmer format.

## Required behavior

1. There must be at least three linked content pages.
2. Every content page must include:
   - a return link back to the homepage
   - a page-specific title and summary
   - sections with readable prose, lists, and evidence blocks
   - a clear connection to the main scrollytelling narrative
3. The return link should preserve the idea of "go back to the scene you came from" when possible.

## Suggested page topics

- Why this project matters
- How the data and tool work
- How the spec-driven process improved the build

## Exit checks

- `dist/why-this-project.html`, `dist/how-it-works.html`, and `dist/spec-driven-process.html` exist after build.
