# Spec 03: Visual System

## Direction

The design should feel editorial and evidence-driven rather than app-shell-first. It should be warmer and more intentional than the current prototype, while still feeling like a serious class project.

## Required traits

1. Strong type hierarchy with a clear display face and a readable body face.
2. A non-flat background treatment that supports the story.
3. Sticky scenes and scroll states that remain legible on laptop and mobile widths.
4. Visual assets that make the site feel authored, not placeholder-driven.
5. Shared colors, spacing, and component styling between the homepage and content pages.

## Constraints

- Preserve accessibility: strong contrast, clear focus states, and readable paragraph widths.
- Keep the tool usable even if the homepage becomes more expressive.
- Use the existing local project assets where practical.

## Exit checks

- The homepage and content pages visibly share one system.
- The layout remains readable at narrow widths.
