## Good ideas harvested

1. The homepage is a story, not a dashboard. It reveals one clear idea at a time through stacked scenes.
2. The scroll experience pairs a sticky visual field with step-based text so motion feels purposeful.
3. Content pages are regular reading pages, but they still feel connected to the presentation through consistent typography, layout, and a return link.
4. The assignment repo treats process as part of the deliverable: references, specs, phases, and explicit exit checks.
5. The strongest lesson in the guide is that AI needs durable context in files, not just prompts in chat.

## What we are porting into this project

- A scrollytelling homepage that turns the affordability question into a guided narrative.
- Linked content pages that expand the story without losing the user.
- A visible spec-driven folder structure so the project demonstrates process, not only polish.

## What we are not copying

- The BSEAI topic, copy, or structure.
- The full multi-dozen-page doctrine from the teacher repo.
- Next.js-specific implementation details. This project already runs on Vite + React and should stay aligned with that stack.
