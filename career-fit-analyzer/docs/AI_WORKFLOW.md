# AI Workflow

AI was used intentionally for this assignment in four ways:

1. Role research: comparing current AI product engineering, applied AI, and entry-level software engineering postings.
2. Gap analysis: identifying repeated requirements that were not strongly represented in the resume or portfolio.
3. Project scoping: choosing a project small enough to finish well but relevant enough to discuss professionally.
4. Documentation: turning the work into a clear README, presentation outline, and portfolio description.

## Judgment Applied

The final project scope was kept intentionally small. Instead of pretending to have production AI engineering experience, the project demonstrates beginner-credible proof:

- real job descriptions as source inputs
- transparent keyword and skill matching
- a working browser interface
- separated analysis functions
- automated tests
- clear documentation of limitations

## Limitations

This analyzer is not a replacement for a recruiter, ATS platform, or semantic embedding model. It is a professional learning artifact that shows how AI-assisted research can become a focused software project.
